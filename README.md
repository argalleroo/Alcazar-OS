# Alcazar-OS
Alcázar-OS es una distribución basada en Debian para OSINT, ciberinteligencia, análisis forense e IA local mediante Alcaza-IA. Nace como parte de un TFM, pero es un proyecto activo y con futuro: continuará manteniéndose, ampliándose y mejorándose hasta alcanzar una versión definitiva, estable y preparada para su distribución.
